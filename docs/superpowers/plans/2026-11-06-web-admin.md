# Web Admin (sprint 06) — Implementation Plan

**Goal:** replace the `apps/admin/src/app/page.tsx` mockup with the real panel.

**Spec:** `docs/superpowers/specs/2026-11-06-web-admin-design.md`
**Tasks:** `docs/tasks/sprint-06-web/task-05.md` … `task-11.md`.

## Global Constraints

- English code/comments/commits; Spanish docs. Every visible string is a literal `t("...")`; 9 locales complete.
- Panel reads `/api/v1` only (ADR 0004/0005). No fake data in production code.
- Colors only via semantic tokens. No `any`. No `console.log`. Loading/empty/error always.
- Gates: `pnpm lint && pnpm tsc && pnpm test && pnpm i18n:check && pnpm --filter admin build`.
- One QA/OWASP audit and one style review per task, by an agent that did not write it.
- Design/UX review is binding: docs/superpowers/specs/2026-11-06-web-admin-ux-review.md (IA, header, patterns, states, checklist).
- Every page audit answers the three mandatory questions of the UX review §10 (self-actions, data provenance, setup-to-profile consistency).
