Qué estás viendo

Es el esqueleto base, no OweNo. El dashboard incrusta un widget de demo para enseñar el host; el widget real de OweNo llega en el mockup F1. La campana está en estado vacío porque FCM sigue bloqueado. El FAB abre la hoja de «añadir»; OweNo se conecta en la tarea 03. La pantalla de invitación es el destino del deep link: muestra la instancia, canjea el token y aplica el idioma inicial después del alta.

  • Variante A: OweNo es pestaña principal. Escala mal si mañana hay muchos módulos; el Inicio enlaza «Ver todos los módulos».
  • Variante B: «Módulos» es el lanzador; OweNo se abre dentro como un módulo más. Escala mejor con muchos módulos.
  • Ambas comparten login, dashboard, ajustes, idioma, tema, campana y FAB. No hay selector global de grupo: los grupos son de cada módulo.
