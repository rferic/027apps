05 / FAQ
¿Qué necesito para montarlo?

Un proyecto de Supabase (Postgres + Auth) y una cuenta de Vercel, o un servidor propio. La guía del repositorio cubre claves, migraciones, dominio, correo y el primer administrador.

¿Cuánto cuesta?

La licencia es MIT: no hay suscripción. Pagas tu hosting; los planes gratuitos de Vercel y Supabase son suficientes para una familia.

¿Cómo se actualiza?

Con el mismo flujo que el desarrollo: git pull, migraciones y deploy. El CI aplica las migraciones por entorno.

¿Dónde están los datos?

En tu proyecto de Supabase y tu dominio. No hay servidores nuestros en medio ni analítica de terceros.

¿Y la app de la familia?

Es la otra cara: se descarga desde GitHub Releases y habla con tu instancia por la API v1. El panel sigue siendo la parte de escritorio.
